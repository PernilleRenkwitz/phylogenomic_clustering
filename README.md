# phylogenomic_clustering
Phylogenomic SNP clustering analysis

## Purpose
Produce a phylogenic tree cluster for listeria isolates from denmark and add metadata to analyse the clusters. It is done using bioinformatic pipelines to process raw fastq sequences and perform variant calling on them to find variants and cluster them accoring to SNP differences.
